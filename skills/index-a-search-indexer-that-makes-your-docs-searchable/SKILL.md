**Category:** docs | **Difficulty:** easy | **Est. time:** ~20 min | **Prerequisites:** Docs source, hosting (Vercel/GitHub Pages)

## Objective

The agent must deliver: a working index setup for a search indexer that makes your docs searchable. The result should be complete, verified, and usable without further help.

## When to use this skill

- When you need to index a search indexer that makes your docs searchable and want it done quickly or automatically.

## Steps

1. Read the Objective: the deliverable is index a search indexer that makes your docs searchable.
2. Set up the tooling (Docusaurus/Mintlify/GitHub Pages) per best practice.
3. Write the docs content for a search indexer that makes your docs searchable with real, useful information.
4. Add search + navigation; make sure pages are reachable.
5. Deploy and verify the published docs work.
6. Document how to update the docs in the future.

- [ ] Docs instructions are clear; the project owner can follow them.
