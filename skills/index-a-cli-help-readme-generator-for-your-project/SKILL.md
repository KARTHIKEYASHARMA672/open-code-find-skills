# Index a CLI help/README generator for your project

**Category:** docs | **Difficulty:** easy | **Est. time:** ~20 min | **Prerequisites:** Your project

## Objective

The agent must deliver: a working index setup for a CLI help/README generator for your project. The result should be complete, verified, and usable without further help.

## When to use this skill

- When you need to index a CLI help/README generator for your project and want it done quickly or automatically.

## Steps

1. Read the Objective: the deliverable is index a CLI help/README generator for your project.
2. Set up the tooling (Docusaurus/Mintlify/GitHub Pages) per best practice.
3. Write the docs content for a CLI help/README generator for your project with real, useful information.
4. Add search + navigation; make sure pages are reachable.
5. Deploy and verify the published docs work.
6. Document how to update the docs in the future.

## Validation (how to verify it worked)

- [ ] Open the published docs; all pages render without errors.
- [ ] The new docs appear in search results and navigation.
- [ ] Docs instructions are clear; the project owner can follow them.
