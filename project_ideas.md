## 15 Portfolio-Worthy Projects (each a nice case-study to show off)

1. **AI DevOps Agent Hub** — A personal agent that watches your GitHub repos/CI, opens AI-fix PRs, auto-deploys, and triages issues with comments. Shows "AI-first" + agentic coding.
   - Stacks: OpenCode/Claude + GitHub Actions + GitHub API, Vercel-free.
   - Effort: High.

2. **Parallel Agent Fleet Orchestrator** — The core of "how do I deal with any problem with AI?": an orchestrator that launches **N agents in parallel** on your task list and merges results. Your strongest portfolio piece.
   - Stacks: OpenCode SDK + Node/TS + GitHub, free.
   - Effort: Medium-High.

3. **Next.js AI Project Dashboard** — Portfolio of all your AI projects (ai-os, archon, cityos, reality-engine, nexus-factory…), with AI-generated summaries and GitHub webhook status sync.
   - Stacks: Next.js/React/TS, Vercel (free), GitHub API.
   - Effort: Medium.

4. **OpenCode Skills Registry + Docs Site** — Beautiful docs for your 1000 skills: search, AI summaries, categories, links to folders, sync with GitHub (`new-skills`).
   - Stacks: Vite + GitHub Pages/Vercel, free.
   - Effort: Medium.

5. **RAG Over All Your Repos** — Ask questions over your codebases ("why did we refactor X?"). MCP server + RAG (like your `agent-platform` modules).
   - Stacks: MCP + LangChain/RAG, free-tier embeddings, GitHub API.
   - Effort: High.

6. **Auto Docs Generator for New Projects** — New project scaffold auto-generates a Docusaurus/Mintlify-style docs site with AI, including style, nav, search.
   - Stacks: Docusaurus/Mintlify + AI, GitHub Pages/Vercel, free.
   - Effort: Medium.

7. **Vercel Deploy Optimizer** — Tool that audits Vercel deploy logs and suggests free-tier optimizations.
   - Stacks: Next.js + Vercel API + AI, free.
   - Effort: Medium.

8. **Notion Project Board + AI Agents** — Projects board where agents update status via GitHub webhooks.
   - Stacks: Notion API + GitHub Actions, free.
   - Effort: Medium.

9. **AI e2e Testing Framework** — Framework where AI writes E2E tests; Playwright locally (free).
   - Stacks: Playwright/Selenium + AI, free.
   - Effort: High.

10. **Streaming Video Dashboard** — FFmpeg dashboard for trimming/exporting your videos.
    - Stacks: ffmpeg + web app, free.
    - Effort: Low-Medium.

11. **Pothole Map Dashboard** — Map dashboard for potholes with AI classification (your pothole projects).
    - Stacks: Leaflet/MapLibre + AI + DB (Supabase free), Vercel free.
    - Effort: Low.

12. **STM32 Smart-Home Demo App** — Web app controlling STM32 projects via their GPIO API.
    - Stacks: Web app + STM32 device, free.
    - Effort: Medium.

13. **Skill Finder** — Search/filter app over your skills + memory ("automate a scraper" → get skill).
    - Stacks: Next.js + your skills repo, free.
    - Effort: Low.

14. **Auto Resume Generator** — AI updates your resume bullets from your projects (like your "CV should be update" notes).
    - Stacks: Web app + AI, free.
    - Effort: Medium.

15. **Idea Suggester from Your Projects** — AI reads your folders + suggests "build this" ideas and converts them to skills (synergy: idea → skill in the registry).
    - Stacks: AI + Next.js, free.
    - Effort: Medium.
